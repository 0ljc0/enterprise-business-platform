# 业务平台操作手册

## 验收入口与账号

访问 `http://127.0.0.1:18081`，输入验证码后登录。此入口使用独立演示数据；以前的业务数据仍在原业务库。

验收账号：s2_platform（平台）、s2_a_admin（企业A管理员）、s2_b_admin（企业B管理员）、s2_a_hr（人事）、s2_a_business（业务）、s2_a_finance（财务）、s2_a_employee（员工）。演示密码见源码目录的 `seed-credentials.local.txt`；初始系统管理员随机密码另见验收目录config/initial-admin.local.txt，不在公开手册写密码。

已完成的整条验收流程可用 s2_unbound（新入驻企业管理员）和 s4_applicant（新入驻员工）查看，企业编号3、归档项目编号1。

## 主流程

1. 平台建立未归属企业的申请账号。该账号在“企业入驻”填写企业资料并上传营业执照、提交申请；平台在“入驻审核”审核。驳回时申请人查看意见、修改并重提；通过后重新登录获得企业管理员权限。
2. 员工申请账号在“员工入驻”选择企业并提交；该企业管理员或人事在“员工审核”处理。通过后重新登录，企业可在“员工管理”维护资料；仅企业管理员可以授予企业业务角色。
3. 平台在任务管理新建并发布共享任务，维护单位报价；企业在“可报名任务”报名，由平台审核。企业自行发布的任务仅内部使用，不能跨企业报名。
4. 企业以审核通过的报名创建执行项目，分配给本企业在职员工。员工在个人任务中领取，按日期填报工作量并提交，企业核对确认。未确认草稿和待审工作量不计进度。
5. 企业业务人员按日填报元为单位的业务产值并提交，退回后修正重提。规则仅计工作日，节假日由平台日历配置；漏报只提醒，补齐后提醒解除，权限一直保留。
6. 有权限的管理者查看统计工作台与对应报表，筛选日期、导出Excel。企业只看本企业，人事只看人员，财务无人员明细和报价修改权限。未报价不算零元，计划量×单价只作估值，与每日实际填报产值分开。
7. 确认工作量达到目标后，员工完成分配任务，企业完成并归档项目；完成和归档后不继续修改执行数据。人员离职前处理未完成分配，离职会撤销企业权限和门禁台账授权。

门禁功能为平台授权台账，不代表实际硬件已经接通。财务核对比较月度填报与核对快照，不处理银行支付。人员统计是当前档案状态，不重建历史时点人数。

## 用户最终验收

分别用平台、企业管理员、员工账号走完上述流程；额外用企业B访问企业A数据验证拒绝。检查图表、Excel、未报价状态、日志和备份恢复记录。确认正常后即可签署最终验收；当前自动化检查通过不替代用户现场确认。

若打不开页面：确认MySQL和Redis服务运行，再在验收目录运行启动命令；已启动提示端口占用时直接访问页面，不重复启动。后端错误看logs/sys-error.log；代理502看Nginx日志和后端启动状态。原开发环境前端仍使用npm.cmd启动，验收站点不需要打开Vite终端。
