# 第十阶段变更与交付

本阶段无新增业务表、字段、菜单或业务接口；数据库交付为最终完整结构与干净初始化数据。已有业务库无需执行新的结构迁移。

- application-release.yml：独立发布配置，必填外部数据源和令牌密钥、管理页面关闭、线程/连接池及日志级别。
- SecurityConfig：security.management-pages-enabled=false时后端明确拒绝Druid/Swagger/API文档路径；默认开发行为保持兼容。
- logback.xml：支持LOG_PATH环境变量；仍按天轮转保留60天。
- login.vue：移除默认填入的演示用户名与密码。
- deploy/stage10：干净打包脚本、官网Nginx来源校验值、代理模板、首次安装/启动/停止/备份/恢复校验工具。
- tests/stage02：验证码测试辅助支持选择独立Redis库。
- tests/stage10：当前结构回归、整链路、从零安装、最终部署检查、备份恢复演练结果及Excel样本。

修复了从零安装中发现的Java辅助类路径、Nginx临时目录、Windows后台启动与脚本执行策略兼容、初始随机密码长度问题。工具对已有目录配置和数据库采取拒绝覆盖方式，停止进程前检查所属路径。未全局修改PowerShell执行策略，未改变原MySQL/Redis服务的账户或监听配置。

源码分支stage10-testing-deployment；实际验收目录D:/code/ruoyi-release10；最终干净包D:/code/ruoyi/release/ruoyi-stage10-clean.zip。干净包自带部署手册、SQL、JAR、前端、Nginx及工具，但不带本机运行密钥和演示账号数据。

第十阶段之前源代码备份：工作区backups/before-stage10。历史考试系统备份继续保留。现有开发数据库ry_platform_stage02未被本轮测试写入。验收库和全部回归库独立创建，失败安装留下的半成品数据库和停止的干净检查目录保留便于追溯，未自动删除。

本机验收完成后，由用户现场确认最终里程碑M3。公网服务器部署、证书接入、异地备份和计划任务启用尚未执行，均在部署文档写明操作条件与步骤。
