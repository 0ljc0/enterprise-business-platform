# 第九阶段：数据统计与报表输出

交付日期：2026-10-26。已完成开发、自测及测试环境图表检查，待用户验收。

## 使用方法

1. 启动后端与前端；若已有服务运行，先重启后端，刷新前端并重新登录。
2. 打开“业务平台 → 统计工作台与报表”。
3. 选择报表、日期与日/月粒度，点击查询。平台可选择企业；企业用户只能查看本企业。
4. 点击“导出Excel”下载当前筛选范围的完整结果，导出不受当前列表分页限制。
5. 有报价权限的发布方打开“任务报价”，填写单位报价及变更原因。已有项目在报价明细中查看快照；执行中的缺价项目可由企业管理者留痕补录。

## 角色范围

| 角色 | 报表范围 | 报价操作 |
| --- | --- | --- |
| 平台管理员 | 全部七类，可跨企业筛选 | 维护自己发布的平台任务报价 |
| 企业管理员 | 本企业除平台全量外全部 | 本企业内部任务报价、执行中缺价快照补录 |
| 企业业务 | 工作台、产值、项目执行、预估 | 同上 |
| 企业财务 | 工作台、产值、项目执行、预估、月度核对 | 只读 |
| 企业人事 | 人员统计 | 无 |
| 普通员工 | 无统计菜单和接口权限 | 无 |

接口再次校验角色和企业归属，不能靠修改企业编号越权。Excel使用相同权限校验。

## 统计口径

- 工作台企业、员工和项目为当前状态数量；本月产值为本月已提交或已确认的每日填报金额。员工人数按用户去重，人员档案行数另外展示。
- 业务产值仅汇总 SUBMITTED、CONFIRMED，金额单位为元；草稿和退回不计入，分别列出数量。已确认金额是已提交金额的子集，图表不做叠加。
- 日/月趋势在所选日期范围内汇总，缺数据日期补零。默认本月首日至今天。漏报沿用第六阶段工作日与节假日配置，只提醒，不限制权限。
- 项目进度是当前累计已确认工作量／企业承诺目标量；所选期间确认工作量单列，不能混同累计进度。完成、归档项目保持只读。
- 发布方维护每工作量单位报价，计划工作量×项目报价快照形成预估金额。每条明细四舍五入到分后相加。未报价明确显示“未报价”，不能当作零元；缺任意一条报价时完整项目估值为空，已有报价部分小计另列。
- 估值、已确认工作量与企业每日填报产值分别统计，预估金额不当作实际收入。本阶段不处理收付款、银行流水或支付对账。
- 新关联项目保存当时的报价、版本和时间。后续任务改价不重算既有快照。执行中的空快照可留痕补录，已有快照不覆盖；完成或归档项目不补录。草稿任务修改工作量单位时清空原报价并记录变更。
- 人员统计反映当前人员档案、在职/离职状态及所选期间入离职日期计数，不是历史时点在岗人数重建。
- 财务月度核对按完整自然月展示，即使查询日期只覆盖月内部分日期；当前已提交/已确认填报总额与第六阶段最近一次月度核对快照比较。没有快照时差额留空，不能虚构为零。状态沿用待核对、退回、确认。
- 平台全量报表覆盖企业、人员档案、项目执行、每日业务产值、月度核对、工作量明细，不导出登录秘密或附件内容。

## 范围及Excel约定

日期跨度最多366天，截止日不得晚于今天。每类结果最多10000行，超过则明确拒绝并提示缩小范围，不静默截断；工作台部分汇总也受同一结果上限约束。Excel包含范围说明、中文表头、冻结首行、筛选和汇总页。超出Excel安全数值精度的金额与编号保存为精确文本；未报价留空；用户输入文本不会成为Excel公式。接口金额使用十进制字符串避免浏览器精度丢失。

## 数据库与代码交付

迁移脚本：`RuoYi-Vue-backend/sql/stage09/01_statistics.sql`，已备份并应用到业务库 `ry_platform_stage02`，不要重复执行。未修改原考试数据库。

后端 `com.ruoyi.web.biz` 下新增 StatisticsService、StatisticsController、StatisticsExcel；修改 ExecutionService、TaskService。复用现有数据库访问与权限体系，无新增Mapper文件和依赖。前端 `src/views/business/statistics/index.vue` 内包含接口调用及ECharts展示。

| 接口 | 用途 |
| --- | --- |
| GET /statistics/options | 当前用户可选报表与范围 |
| GET /statistics/report | kind、companyId、from、to、group、pageNum、pageSize |
| GET /statistics/export | 同查询筛选，下载XLSX |
| GET /statistics/price-tasks | 当前发布方可维护的任务 |
| PUT /statistics/prices/{id} | 单价、版本和原因，版本冲突拒绝 |
| POST /statistics/projects/{id}/price-snapshot | 留痕补录执行中缺价快照 |

kind取值 overview、outputs、projects、estimates、personnel、reconciliation、full；group取 DAY 或 MONTH。完成本阶段用户验收后进入下一阶段。
