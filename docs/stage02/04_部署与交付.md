# 第二阶段部署与交付

## 本次实施

第一阶段需求已由用户明确确认。本阶段已完成：13张表、ER图、字段与索引约束、六角色菜单矩阵、后端企业过滤与越权校验、状态字典、演示数据、权限验证页面、真实接口验收。

数据库：ry_platform_stage02，与原考试库ry-vue独立。Redis数据库2，与原库0隔离。原考试源码D:/code/ruoyi-exam-backup-20261023保持不变；原库备份见当前工作区backups/ry-vue-before-stage02.sql。不要对原库执行stage02初始化脚本。

## 启动

后端在D:/code/ruoyi/RuoYi-Vue-backend执行：

```powershell
mvn package -DskipTests
java -jar .\ruoyi-admin\target\ruoyi-admin.jar
```

后端8080。前端在D:/code/ruoyi/RuoYi-Vue3执行：

```powershell
npm.cmd run dev -- --port 5173
```

若先前终端还运行旧后端，Ctrl+C后再启动，旧进程不会自动加载新代码。使用测试账号.local.md的s2_账号登录查看业务平台，不能用原考试库账号验证新业务角色。新库保留若依基础管理员；演示平台管理员使用s2_platform，不授予系统管理权限。

## 文件

- sql/stage02/01_schema.sql：建表（不含DROP），仅首次执行。
- sql/stage02/02_permissions.sql：菜单、角色、字典。
- sql/stage02/03_demo.local.sql：本地演示企业/账号/任务数据，不提交版本库。
- ruoyi-admin/src/main/java/com/ruoyi/web/biz：Controller、Service、Mapper和模块白名单。
- src/views/business/records/index.vue、src/api/business/records.js：业务记录页面及API。
- tests/stage02：接口和数据库约束验收源文件。测试依赖隔离演示库，仅在专用测试库使用。

## 范围与限制

当前提供业务记录查询和产值草稿新增/修改，已实现操作日志。入驻审批、任务流转、门禁硬件同步、财务结算、附件下载、导出和企业人员授权将在后续阶段实现，当前不暴露通用写入接口。审批轨迹字段和状态字典已设计。

首次部署脚本会拒绝覆盖已有目标库。SQL不是幂等迁移，不可重复导入基础初始化脚本。回退时切回实施前配置与源码；原库及考试备份未修改，不自动删除新库。测试账号密码仅保存在local文件，验收后停用s2_账号。sys_user/sys_role等基础登录权限能力全部复用若依。
